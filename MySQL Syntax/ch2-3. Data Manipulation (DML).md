# Chapter 2-3 — Data Manipulation: `INSERT` / `UPDATE` / `DELETE`

> The DML statements that change the contents of a table.

## 1. `INSERT` — adding rows

```sql
-- full row, columns in table order
INSERT INTO member VALUES ('BLK', 'BlackPink', 4, 'GN', '055', '00000000', 163, '2016-08-08');

-- partial: list the columns you provide; the rest take DEFAULT / NULL
INSERT INTO member (mem_id, mem_name, mem_number, addr)
VALUES ('SPC', 'WJSN', 13, 'SE');

-- multiple rows in one statement
INSERT INTO member (mem_id, mem_name, mem_number, addr) VALUES
    ('GRL', 'GirlsGen', 8, 'SE'),
    ('ITZ', 'ITZY', 5, 'GN');
```

### `AUTO_INCREMENT`

A column marked `AUTO_INCREMENT` (e.g., `buy.num`) auto-fills with the next integer; insert `NULL` or omit it.

```sql
INSERT INTO buy (mem_id, prod_name, group_name, price, amount)
VALUES ('BLK', 'wallet', NULL, 30, 2);     -- num is generated automatically

SELECT LAST_INSERT_ID();                  -- the value just generated
ALTER TABLE buy AUTO_INCREMENT = 100;     -- restart counter at 100
```

### `INSERT … SELECT` — bulk copy

```sql
INSERT INTO member_backup
SELECT * FROM member;        -- copy all rows from another table/query
```

## 2. `UPDATE` — changing rows

```sql
UPDATE member
SET addr = 'SE', height = 165
WHERE mem_id = 'BLK';
```

> **Warning:** omit `WHERE` and **every row** is updated. Always confirm the `WHERE` clause first.

```sql
-- computed update across all matching rows
UPDATE buy SET price = price * 1.5 WHERE group_name = 'digital';
```

## 3. `DELETE` — removing rows

```sql
DELETE FROM member WHERE mem_id = 'SPC';
```

> Same warning: `DELETE FROM member;` with no `WHERE` empties the table.

## 4. Deleting from a large table — `DELETE` vs `DROP` vs `TRUNCATE`

| Statement | Removes | Structure kept? | Speed | Rollback? |
| --- | --- | --- | --- | --- |
| `DELETE FROM t;` | rows (one by one, logged) | yes | slow | yes (DML) |
| `TRUNCATE TABLE t;` | all rows (reset) | yes | very fast | no (DDL) |
| `DROP TABLE t;` | rows **and** table | no | fast | no (DDL) |

Use `TRUNCATE` to quickly empty a table you want to keep; `DROP` to remove the table entirely.

## Key takeaways

- `INSERT` adds, `UPDATE` changes, `DELETE` removes.
- `AUTO_INCREMENT` generates sequential keys; read the last one with `LAST_INSERT_ID()`.
- The `WHERE` clause is what protects you in `UPDATE`/`DELETE` — never run them without checking it.
- For a full wipe, `TRUNCATE` beats `DELETE`; to remove the table too, use `DROP`.
