# Chapter 2-1 — The Basics: `SELECT … FROM … WHERE`

> The single most-used statement in SQL.

## 1. The practice database (`market_db`)

All later examples use this schema (an internet shop managing K-pop groups).

```sql
CREATE DATABASE market_db;
USE market_db;

CREATE TABLE member (                              -- groups
    mem_id     CHAR(8)     NOT NULL PRIMARY KEY,   -- group ID (PK)
    mem_name   VARCHAR(10) NOT NULL,               -- group name
    mem_number INT         NOT NULL,               -- number of members
    addr       CHAR(2)     NOT NULL,               -- region (2 chars)
    phone1     CHAR(3),                            -- area code
    phone2     CHAR(8),                            -- rest of phone number
    height     SMALLINT,                           -- average height
    debut_date DATE                                -- debut date
);

CREATE TABLE buy (                                 -- purchases
    num        INT      AUTO_INCREMENT NOT NULL PRIMARY KEY,
    mem_id     CHAR(8)  NOT NULL,                  -- group ID (FK)
    prod_name  CHAR(6)  NOT NULL,
    group_name VARCHAR(10),
    price      INT      NOT NULL,
    amount     SMALLINT NOT NULL,
    FOREIGN KEY (mem_id) REFERENCES member(mem_id)
);
```

## 2. `SELECT … FROM` — choosing columns

```sql
SELECT * FROM member;                    -- every column
SELECT mem_name, addr FROM member;       -- chosen columns
SELECT addr AS region FROM member;       -- column alias (AS)
```

`*` means "all columns." Order columns however you like. `AS` renames a column in the result only.

## 3. `WHERE` — filtering rows

`WHERE` keeps only rows where the condition is true.

```sql
SELECT * FROM member WHERE mem_name = 'BlackPink';
SELECT * FROM member WHERE mem_number > 6;
```

### Comparison & logical operators

| Type | Operators |
| --- | --- |
| Comparison | `=`, `<>` (or `!=`), `>`, `<`, `>=`, `<=` |
| Logical | `AND`, `OR`, `NOT` |

```sql
SELECT * FROM member WHERE height >= 162 AND mem_number > 6;
SELECT * FROM member WHERE height >= 165 OR mem_number > 6;
```

### Range, set, and pattern

| Keyword | Meaning | Example |
| --- | --- | --- |
| `BETWEEN a AND b` | inclusive range | `WHERE height BETWEEN 163 AND 165` |
| `IN (…)` | matches any in a list | `WHERE addr IN ('SE','GG','GN')` |
| `LIKE` | pattern match | `WHERE mem_name LIKE 'B%'` |

`LIKE` wildcards: `%` = any number of characters, `_` = exactly one character.

```sql
SELECT * FROM member WHERE mem_name LIKE 'A_ink';  -- _ matches exactly one character (matches 'Apink')
```

## 4. Subquery

A `SELECT` nested inside a `WHERE`. The inner query runs first; its result feeds the outer query.

```sql
-- groups taller than Apink's height
SELECT mem_name, height FROM member
WHERE height > (SELECT height FROM member WHERE mem_name = 'Apink');
```

## Key takeaways

- `SELECT columns FROM table WHERE condition;` is the backbone.
- Combine conditions with `AND` / `OR`; use `BETWEEN`, `IN`, `LIKE` for ranges, lists, patterns.
- A subquery returns a value (or set) that the outer query compares against.
