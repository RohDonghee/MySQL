# Chapter 4-2 — Constraints

> Rules that keep data valid and relationships consistent (data integrity).

## 1. The six constraint types

| Constraint | Guarantees |
| --- | --- |
| `PRIMARY KEY` | unique **and** not-null row identifier (one per table) |
| `FOREIGN KEY` | values must exist in a referenced table (referential integrity) |
| `UNIQUE` | no duplicate values (NULL allowed) |
| `CHECK` | values satisfy a condition (MySQL 8.0.16+) |
| `DEFAULT` | a fallback value when none is supplied |
| `NOT NULL` | value is required |

## 2. Primary key

```sql
CREATE TABLE member (
    mem_id   CHAR(8) NOT NULL PRIMARY KEY,
    mem_name VARCHAR(10) NOT NULL
);
-- or as a table-level / composite key:
-- PRIMARY KEY (col1, col2)
```

A PK is automatically unique and not-null, and is automatically indexed (clustered).

## 3. Foreign key

Links a child column to a parent's primary key so orphan rows can't exist.

```sql
CREATE TABLE buy (
    num    INT AUTO_INCREMENT PRIMARY KEY,
    mem_id CHAR(8) NOT NULL,
    prod_name CHAR(6) NOT NULL,
    FOREIGN KEY (mem_id) REFERENCES member(mem_id)
        ON UPDATE CASCADE      -- propagate parent key changes
        ON DELETE CASCADE      -- delete children when parent is deleted
);
```

Referential actions: `CASCADE`, `SET NULL`, `RESTRICT` (default), `NO ACTION`.

## 4. UNIQUE, CHECK, DEFAULT

```sql
CREATE TABLE member2 (
    mem_id   CHAR(8) PRIMARY KEY,
    email    VARCHAR(30) UNIQUE,                       -- no duplicate emails
    height   SMALLINT CHECK (height >= 100),           -- value rule
    addr     CHAR(2) DEFAULT 'SE'                     -- fallback value
);
```

## 5. Adding constraints to an existing table

```sql
ALTER TABLE buy
    ADD CONSTRAINT fk_member_buy
    FOREIGN KEY (mem_id) REFERENCES member(mem_id);
```

Naming a constraint (`fk_member_buy`) makes it easy to `DROP` later.

## Key takeaways

- Constraints enforce **data integrity** at the database level, not in app code.
- PK = unique + not-null + indexed; FK = referential integrity between tables.
- `UNIQUE`, `CHECK`, `DEFAULT`, `NOT NULL` cover the remaining value rules.
- Add or remove them after creation with `ALTER TABLE … ADD/DROP CONSTRAINT`.
