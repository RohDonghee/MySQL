# Chapter 3-3 — SQL Programming

> Control-flow inside SQL: conditionals, loops, and dynamic statements. These run inside stored routines (note the `DELIMITER`).

## 1. `IF` — conditional branching

```sql
DELIMITER //
CREATE PROCEDURE if_proc()
BEGIN
    DECLARE v INT;
    SET v = 100;
    IF v = 100 THEN
        SELECT 'equals 100';
    ELSEIF v > 100 THEN
        SELECT 'greater';
    ELSE
        SELECT 'less';
    END IF;
END //
DELIMITER ;
```

There is also an inline **`IF()` function**: `IF(condition, true_value, false_value)`.

```sql
SELECT mem_name, IF(height >= 165, 'tall', 'short') AS class FROM member;
```

## 2. `CASE` — multi-way branching

Cleaner than nested `IF` when there are several conditions.

```sql
SELECT mem_name,
    CASE
        WHEN height >= 170 THEN 'A'
        WHEN height >= 165 THEN 'B'
        WHEN height >= 160 THEN 'C'
        ELSE 'D'
    END AS grade
FROM member;
```

## 3. `WHILE` — looping

```sql
DELIMITER //
CREATE PROCEDURE while_proc()
BEGIN
    DECLARE i INT;  DECLARE total INT;
    SET i = 1;  SET total = 0;
    WHILE i <= 100 DO
        SET total = total + i;
        SET i = i + 1;
    END WHILE;
    SELECT total;          -- 5050
END //
DELIMITER ;
```

Related loop controls: `REPEAT … UNTIL … END REPEAT`, `LOOP … END LOOP`, `ITERATE` (continue), `LEAVE` (break).

## 4. Dynamic SQL

Build a statement as a string at runtime, then `PREPARE` and `EXECUTE` it. `?` are placeholders.

```sql
SET @table = 'member';
SET @sql = CONCAT('SELECT * FROM ', @table);
PREPARE stmt FROM @sql;
EXECUTE stmt;
DEALLOCATE PREPARE stmt;

-- with a bound parameter
SET @id = 'BLK';
PREPARE stmt2 FROM 'SELECT * FROM member WHERE mem_id = ?';
EXECUTE stmt2 USING @id;
DEALLOCATE PREPARE stmt2;
```

> Dynamic SQL is powerful for variable table/column names; using `?` placeholders also guards against SQL injection.

## Key takeaways

- `IF`/`CASE` branch; `IF()` is the inline expression form.
- `WHILE` (and `REPEAT`/`LOOP`) loop, with `LEAVE`/`ITERATE` to break/continue.
- Dynamic SQL = `PREPARE` → `EXECUTE` → `DEALLOCATE`, with `?` placeholders.
- All of this lives inside stored routines, so set a custom `DELIMITER`.
